@switch (mode) { @case ('ios-manuel') {

🌸 Installe Mira sur ton iPhone

  1. Appuie sur le bouton Partager dans la barre de ton navigateur (en bas ou en haut selon le navigateur)
  2. Choisis « Sur l'écran d'accueil » (fais défiler le menu si besoin)
  3. Appuie sur « Ajouter »

Tu retrouveras Mira comme une vraie appli, en plein écran.

Tu ne vois pas « Sur l'écran d'accueil » ? Ouvre Mira dans Safari.

} @case ('android-manuel') {

🌸 Installe Mira sur ton téléphone

  1. Ouvre le menu de ton navigateur (les trois points ⋮ ou les trois barres ☰)
  2. Choisis « Installer l'application » ou « Ajouter à l'écran d'accueil »
  3. Confirme avec « Installer » ou « Ajouter »

Le nom exact change selon ton navigateur (Chrome, Firefox, Samsung Internet…). Tu retrouveras Mira comme une vraie appli.

} @case ('installable') {

} @case ('in-app') {

Ce navigateur intégré ne permet pas d'installer l'application. Ouvre ce lien dans ton navigateur habituel (Safari ou Chrome) avec le menu ⋯ ou ⋮, puis « Ouvrir dans le navigateur ». Tu pourras ensuite ajouter Mira à ton écran d'accueil.
